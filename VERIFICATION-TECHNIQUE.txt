LIMITE AVANT PUBLICATION
Le test graphique réel dans Chromium n'a pas pu être exécuté dans l'environnement de vérification : une stratégie système bloque toutes les URL (URLBlocklist « * ») et désactive les outils de développement. Les tests de logique ci-dessus sont des simulations JavaScript avec stockage local simulé, pas un essai tactile dans un vrai navigateur.

Cette archive est une candidate de publication techniquement vérifiée, mais pas une certification visuelle finale. Avant une annonce publique, ouvrir le site sur un téléphone réel et vérifier au minimum :
1. JOUER → aller jusqu'à la fin du Volet I et utiliser « Poursuivre vers Hauterive ».
2. Dans le Volet II, classer les feuillets, demander l'indice SEUIL, recharger la page et vérifier que le classement reste présent.
3. Tester les boutons, les images et l'absence de débordement horizontal à 360–390 px de largeur.
4. Tester le médaillon sonore sur une interaction volontaire (les navigateurs mobiles bloquent l'autoplay).

La clé de stockage historique « feufollet_grimoire_v1 » est conservée volontairement pour préserver les sauvegardes déjà enregistrées dans les navigateurs des joueurs.
